# M1A — 独立纯 Simulink PI-FOC 浮点基线

日期：2026-10-23。文档基线：`main@2e10c2dc576648165f541ad5b1530ef90c1e3791`，PR44 已合并。
状态：设计与验收范围，待 Review；本次文档提交没有创建 SLX、执行仿真或生成 HDL。

## 1. 本阶段目标和边界

用户已经明确：以纯 Simulink PI-FOC 为基线，统一电机模型、调制方式和控制周期，另存一个新模型，参数仍以外部 `.m` 文件加载进工作区为主。

本设计将 M1 拆为 M1A（本阶段：独立浮点基线）和后续 M1B（运行管理恢复）。M1A 不同时引入对齐渐降、软件故障恢复、行程管理、实际测速滤波或新通信接口；现有算法限幅、必要的使能/PI 复位和 PWM 禁止行为不能丢失。新模型不是可直接上电的完整实机控制器。

正式算法来源为 `PMLSM_ThreeLoop_Simple/Control_Task_10kHz/FOC_Algorithm`，外环和 plant 也从经过核查的 Simple 来源保留。完整 MIL 与 DSP 仅作为语义参考，不合并三套旧模型、不改写旧文件，也不再以手写 FOC 作为必须沿用的实现底座。

新文件名是本阶段交付目标，不表示它们在当前文档 PR 中已经存在。后续实现如发现同名本地文件，先保留并报告，不覆盖。

优先使用 M0 审计过、仍与其对应的用户本地 Simple 保存版本作为另存来源。实施前在原目录核对当前版本与 M0 的区别，尤其是 SLX、初始化脚本、MAT 时间序列和交互回调这一整套关系。如果本地又有变化，按实际内容记录，不用 Git 旧版强制覆盖。来源中纯 Simulink 算法、plant 和参数应有可定位的路径/数值记录；新提交不能依赖只有该电脑才有的旧 MAT。

参考快照和旧模型原样保留。源模型的 backend0 对照可在独立进程/临时内存配置中完成，不保存回原 SLX；不得在用户未保存的模型上做转换或关闭其会话。仅在新副本中去掉旧 HDL/XSI、交互准备和不再使用的后端分支。最终新模型不依赖 `CONTROL_BACKEND`、`FPGA_Cosim_Enable`、`.Xil`、XSI DLL 或 HDL Verifier 的初始化。

## 3. 外部 .m 与工作区约定

采用一个明确的参数入口：外部 `.m` 脚本在 MATLAB **基础工作区（Base Workspace）**中加载/计算本模型所需变量。脚本是默认参数和默认场景的可读源文件；不以隐藏 Model Workspace 数值、MAT 文件或数据字典作为第二套权威源。

推荐使用过程为：在包含新文件的目录或已正确配置的项目路径下执行 `init_PMLSM_PI_FOC_Float_Baseline`，再打开新模型并点击 Run。再次修改 `.m` 后显式重新执行脚本，再运行；临时工作区修改不会被模型回调悄悄覆盖，正式结果必须记录实际生效值。

参数初始化职责：

1. 脚本按电机、时基、控制器、逆变器、工况、初态/观测分节；必需默认值每次执行均明确赋值，不用“变量存在就沿用旧值”掩盖脏工作区。
2. 可调用现有纯计算辅助函数 `design_PMLSM_three_loop.m`、`pmlsm_scurve_profile.m`，必须确认路径可解析且没有隐藏 base/MAT 依赖。辅助函数不形成第二套电机参数定义。
3. 新模型中不保留同名 Model Workspace 参数遮蔽基础工作区；mask 仅允许明确的局部派生值/配置，不藏另一套电机、PI 或时基常量。记录变量解析来源并实际检查关键参数。
4. 移除新副本中的旧 `reload(ModelWorkspace)`、`pmlsm_interactive_cosim_init` 和旧 co-sim PreLoad 初始化。`InitFcn` 如保留，仅做必需参数/周期关系校验，不重载旧脚本、不重置用户选择、不构造或改线。
5. 未初始化时给出包含新脚本名称的明确错误，不能误用上次运行其他模型遗留的参数。用本阶段配置标识加必需字段/值检查，而不是仅检查一个 `Udc` 是否存在。
6. 不执行 `clear`、`clear all`、`clc`、`close all` 或全局 PATH 修改。脚本只更新其公开的模型变量；测试在隔离 MATLAB 进程中完成，不破坏用户桌面会话。
7. 新模型所需 timeseries/工况数据由可读 `.m` 定义，或使用明确的原生指令块；不再加载旧 `init_PMLSM_ThreeLoop_Simple.mat`。From Workspace 的插值/保持方式必须明确，阶跃不能因默认插值变成斜坡。

本阶段优先显式初始化，而不是同时支持多种自动回调入口。后续如增加自动初始化，仍只调用同一脚本，并另行定义覆盖规则。未配置新模型前，下述名称只是设计要求，不是可运行入口声明。

## 4. 电机模型与物理量统一

新基线中只有一个正在驱动的 PMLSM plant，沿用 Simple 的 dq 电气方程、机械积分和自由运动行为，不替换为新 Simscape 电机、不冻结位置/速度。控制器与 plant 从同一外部参数源读取对应值；有别名需求时只做显式派生赋值，不重复写独立数字。

M0 已查到、应优先保留的基线值：

| 项目 | 值和解释 |
|---|---|
| 相电阻 | `Rs = 2.37 ohm`，不得与线间电阻混用 |
| dq 电感 | `Ld = Lq = 1.745e-3 H` |
| 永磁磁链 | `psi_f = 0.141 Wb` |
| 等效运动质量 | `M = 0.91 kg` |
| 推力系数 | `Kf_peak = 31.4/sqrt(2) N/Apeak`，保留现有峰值/RMS 换算依据 |
| 电气完整空间周期 | `lambda_e = 0.06 m = 60 mm`；极距为 30 mm，二者不能混用 |
| 母线电压 | 默认 `Vdc = 48 V`，控制器限幅/SVPWM与逆变器必须使用同一工况值 |
| 默认摩擦 | 保留源模型当前黏性/库仑摩擦设置，不顺手增加负载或摩擦补偿 |

保留端口单位约定：电流 A（峰值约定）、电压 V、电角度 rad、电角速度 rad/s；机械内部可用 m/m/s，外环及显示继续使用 mm/mm/s，转换位置必须可追溯。由 `theta_e = 2*pi*x_m/lambda_e + offset`、`omega_e = 2*pi*v_mps/lambda_e` 核对角度/速度一致性。

这些数值是现有模型基线，不是本轮重新辨识的实机参数。Kf、磁链和空间周期的物理标定来源应记录，不能为了让两个公式形式相等而静默重算其中一项。若核查发现实质单位或增益错误，单列原值、修正理由和对照，不通过调 PI 掩盖。

## 5. PI-FOC、外环和调制边界

保留 PI-FOC 的 Clarke/Park、dq PI、前馈解耦、圆形电压限幅、反 Park 和现有扇区式 SVPWM。算法和 plant 的实数运算优先 double；布尔使能和调度计数保持适当类型，不强求所有信号都是 double。先固定算法语义，再考虑 HDL 支持，不在本阶段改成另一种 SVPWM、CORDIC 或定点运算。

保留旧状态 PI 和前拍 anti-windup：`x_next = x + Ki*Ts*e - Kaw*du_z`。复位输出、积分状态、`du_z` 的更新行为分别核对，不能因重命名就顺手把所有延迟记忆清零。保留圆限幅的系数、epsilon与执行顺序。

电流增益优先保留 M0 Simple 值 `Kp=8.725`、`Ki=11850`、`Kaw_d=Kaw_q=0.1358166189111748`；速度环和位置环保留 M0 Simple 实际值（约 `Kp_ASR=0.0180334748526811`、`Ki_ASR=1.44267798821449`、`Kaw_s=0.08`、`Kp_pos=22`）。外部脚本可以使用原整定函数计算，但须证明与所选源参数对应；本轮不重整定、不复制 DSP 调试缩放或 MIL 默认 DPCC 参数。

外环、Reference Manager、S 曲线和物理反馈在新副本中保留；默认可以跑三闭环，另提供电流测试工况。外环先是浮点仿真环境的一部分，不代表已经纳入首个 HDL DUT。实际速度差分/滤波延迟本轮不增加。

### 唯一对外调制定义

FOC/SVPWM 对逆变器输出命名为 `duty_u_cmd`、`duty_v_cmd`、`duty_w_cmd`：**死区前、应用更新延迟前的理想上管高电平时间比例**，线性工作区范围为 `[0,1]`。它不是已经装载的 active duty，也不是有符号调制比或门极电平。零电压向量应对应三相各 0.5。

目标主链不依赖 DSP CPU 时钟或 FPGA TBPRD。优先从 SVPWM 的时间/比例结果得到归一化输出；旧原始 counts 及 `1-CMP/(CPU_Clock*T_pwm/2)` 仅作为来源对照关系，不再让 `10000/7500/5000/2500` 混进新主链。可在临时对照分支中保留旧换算，但不长期维护两个有效调制后端。

在沿用旧关系前必须独立验证物理极性：理想逆变器中 `v_phase_i = Vdc*(duty_i - mean(duty))`，再经一致的 Clarke 变换重构 alpha/beta 电压，与 SVPWM 输入比较。覆盖零矢量、六扇区内部、扇区边界两侧和限幅附近；旧输出对照与物理重构两项都要解释。发现旧代码不符合目标关系时报告实质差异，不通过反接 plant 极性或改 PI 强行凑相同曲线。

只保留一个平均逆变器：`command duty -> PWM更新/保持 -> 单一平均死区 -> 原饱和及电压计算 -> plant`。死区前不额外插入会改变源行为的饱和；输入范围校验和算法限幅分开。平均死区为仿真效应，不生成六路开关脉冲；本轮不验证真实门极或 ADC 触发时序。

## 6. 控制时基与更新责任

| 项目 | M1A 基线 |
|---|---|
| PWM 等效周期 | `T_pwm=100 us`，对应 10 kHz |
| 电流环 | `Ts_ACR=100 us`，每 PWM 周期一次 |
| 速度环 | `Ts_ASR=1 ms=10*Ts_ACR` |
| 位置环 | `Ts_POS=10 ms=10*Ts_ASR` |
| plant/固定求解步长 | `Ts_Plant=1 us`，初期沿用已核查的 FixedStepDiscrete 和离散积分方式 |
| PWM 更新等效延迟 | 先保留源 legacy 的半周期 `T_pwm/2=50 us`，只建模一次 |
| 平均死区 | 默认 `1 us`；理想对照工况为 0；不是求解步长或计算延迟 |

所有比例由一个时基定义区计算并检查整数倍；同一数字出现在多个地方必须说明是别名还是派生量。确认实际 plant 积分块的 SampleTime，而不是只修改模型 FixedStep。改变仿真步长不能同时改变控制采样、死区或更新延迟。

保留源 scheduler 的计数初态、使能/复位和首次触发相位，记录实测 tick 时间。持续使能且电流事件从 t=0 开始时，M0 推导首个速度/位置事件为 0.9/9.9 ms，作为核对点而非不顾条件强制重排。电流采样、计算、保持和 PWM 应用事件须有一张实际时序说明；不把浮点零计算耗时说成已验证 FPGA 实时性能。

本轮的半周期延迟是参考模型约定。未来生成 RTL 时，按实际采样/计算/装载调度替换相应责任，不再额外叠加同一延迟。

## 7. 工况、对照与验收要求

默认演示选择小幅位置工况：1 mm、1.2 s，保留源轨迹结构和经记录的有效参数；默认负载为 0。另设显式负载阶跃场景（可复用 0.8 s 加 0.5 N、1.0 s 撤除）。所有场景从 `.m` 可见，不残留一份看不见的旧 MAT 负载。

在选择源版本、冻结输入及预先记录比较容差之后进行对照；源模型未保存修改、旧 mat 依赖和场景覆写都需记录。对照不能仅与旧手写 RTL 比较，也不能用新旧两侧同时改错作为正确性证据。

| 验收组 | 必需证据 |
|---|---|
| 独立启动/参数来源 | 新 MATLAB 进程仅用仓库新 SLX、外部 `.m` 和明确辅助文件即可 update/sim；不调用旧 prepare/XSI；连续两次初始化与运行可复现；验证必需变量解析来源、旧工作区无关变量不污染结果 |
| 参数确实生效 | 修改外部脚本中的代表性给定/负载并重载，模型实际采用新值；记录修改前后解析值；恢复默认后复跑。电机与控制器关键同名参数不能被 Model Workspace 或 mask 隐藏值遮蔽 |
| 数学与调制 | 使用新模型实际变换块完成有限个数值点；核对 dq PI 复位/AW 前拍记忆；六扇区及边界的旧 counts 对照、独立电压重构；使能关闭时检查所定义的平均电压禁止行为 |
| 闭环与迁移 | 自由运动正负电流、代表性速度/正负位置、理想/死区以及一个 stop/PI reset 工况；复用 Step7 的场景设计，不调用完整历史回归。相同参数/步长/初态/输入下比较所选源的纯 Simulink 路径和新模型 |
| 步长/时序 | 一个代表性工况做 1 us 与 0.5 us 收敛核对；记录控制 tick、duty更新时刻、状态及电压/电流/速度/位置误差，不以步长更小改变控制周期 |

迁移验证逐信号报告最大绝对误差与 RMSE，区分离散状态/事件和连续物理量；事件/模式应一致。仅改变参数存放和等价归一化时，以浮点舍入量级的数值一致为目标，不沿用宽松的旧 RTL 对浮点性能阈值掩盖差异。容差在跑测试前写入报告/测试配置；超差先定位，不事后放宽来获得 PASS。若做必要的单位/极性修正，保留修正前失败和物理证据，单独列出非等价变化并等待 Review。

电流测试不锁死机械运动；不为满足仿真而新增实际行程限制。默认可运行场景不代表实机安全限值。正常停机禁止平均电压与实机快速关断不是同一验收。

## 8. 交付、顺序与停止条件

设计后的实施按可归因的检查点组织：先确认来源/新副本及独立 `.m` 入口，再完成电机/时基一致和调制接口，最后做所需数学/闭环对照；每个检查点保留必要证据，不一次同时恢复运行管理。

最终实现 PR 应包含新 SLX、新初始化脚本、必要且小规模的验证脚本、`coordination/reports/m1a_pure_simulink_float_baseline.md` 和精简结果索引，并更新用户直接运行的说明。报告说明实际源版本、改动子系统、变量解析/单位、调制与时基、场景、检查命令、结果和未完成项。新的模型和所有必要源依赖必须入库，不能只有本地存在或只有文字说明。

原有三个主模型、ControlCore、初始化文件、StudyL1、PWM/FOC RTL和工程不修改。原目录 `D:/Project/FPGA_XC7A200T` 内实施，不新建 clone/worktree，不自动 stash/reset/clean、不覆盖用户改动；`D:/Project/PMSLM_Simulation` 只读。新模型只做必要局部布局，不全局自动布局；不把硬件资料移动、无关缓存或旧仿真产物混入提交。

本阶段不生成 HDL/C、不综合布局布线、不生成 bitstream、不操作硬件、不重整定 PI、不引入真实采集/测量滤波和完整故障恢复。发现已有模型事实与本设计冲突时保留证据并报告，不静默调整物理语义。完成后停在开放 PR，等待 Review，不自动进入 M1B/M2。
