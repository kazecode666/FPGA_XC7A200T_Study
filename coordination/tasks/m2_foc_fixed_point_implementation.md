## 1. 起点、目标和非目标

已查事实：FOC 位于 `PMLSM_PI_FOC_Float_Baseline/Control_Task_10kHz/FOC_Algorithm`，8 输入、3 输出；Vdc 来自内部 Udc 参数，没有显式 Vdc/enable 端口。M1B 的 checkhdl 结果为 1 Error/11 Warning/3 Message，首个错误是 `DutInsideTrigger`；SVPWM 的两条未选中候选除法曾出现 0/0。电流积分状态没有独立硬钳位，速度环 1 A 限幅不等于全部输入/状态的设计上限。

本轮选择完整电流 FOC 作为最小可用定点单元：Clarke、Park、dq PI/解耦前馈、圆限幅及前拍 AW、反 Park、SVPWM。不是只改输入输出 Data Type Conversion，也不是把全部三闭环或电机模型改成定点。

不做：重新整定 PI、死区补偿、运动中重规划、热切闭环、重写 Init_Start/对齐、未知偏置新算法、完整故障管理、ADC/编码器/测速滤波/通信、JMAG/Maxwell、RTL 手写改造、HDL/C 生成、Vivado 构建或硬件操作。已有模型缺陷若会阻止本轮，定位后单列，不借机扩展范围。

不把 M2 和 M3 合并：本轮验证定点数学模型及兼容性；RTL 生成、生成模型延迟、逐位逐周期验证属于 M3，布局布线时序属于 M4。

## 3. 实现、接口和数值合同

### 3.1 一个参考、一个定点实现、一套闭环环境

新增 `simulink模型/PMLSM_FOC_FixedPoint.slx`，正式候选 DUT 为根层 `FOC_DUT`，外面不再包触发/function-call 子系统。它只描述离散 FOC 算法，不复制 Host、外环、逆变器或 plant。

主模型增加停止后生效的 `FOC_Impl_Select`：0=原浮点参考（默认），1=新定点 FOC。这是实现选择，不是运行中闭环模式切换。优先使用本机支持的模型引用；若继承调用约束不允许，采用单一库/子系统引用源并记录原因。独立检查与闭环必须引用同一实现源，禁止复制出两份脱节的定点算法。必要引用/适配不超过实际需要的文件；不额外维护第二套完整电机顶层。

检查点 B 允许在独立实现的工作副本先采用 double 证明抽取/除法修订，随后转换定点。临时结构参考不成为第三套长期生产后端。浮点参考分支仍以 PR49 实际块为准，不能换成手写公式程序替代全部参考。

### 3.2 端口、参数与采样

保留前 8 个输入顺序，新实现增加第 9 个母线端口；适配层显式传入同一个 Udc：

| 输入 | 含义/单位 | 本轮决定 |
|---|---|---|
| 1—3 ia/ib/ic | 同拍三相电流，Apeak | 定点、有符号，范围由 C 冻结 |
| 4 theta_e | 控制电角度，rad | 接口仍用 rad；周期边界及内部相位换算显式记录 |
| 5 omega_e | 控制电角速度，rad/s | 有符号，不是机械 mm/s |
| 6 iq_ref；7 id_ref | 选择/对齐后的真实参考，Apeak | 不接闲置 iq_test_ref 冒充外环输出 |
| 8 PI_Reset_EN | 已有有效控制复位 | boolean，保持原输出/积分及 AW 语义 |
| 9 Vdc_V | 母线电压，V | 新接口；本轮默认接 Udc=48，不代表 ADC 已实现 |
| 输出 1—3 duty_u/v/w_cmd | 死区/应用更新前归一化上管 command duty | 定点无符号；0、0.5、1 必须可表示，不含旧 counts 标度 |

M2 是 100 us 一次更新的离散数值实现；每次调用代表一份有效、同拍输入。暂不新增事务握手、sample_valid、FIFO 或独立 enable 协议。PWM 禁止在原外层，复位从原接口进入；非调用时状态按调度保持。端口的数值定点化不代替硬件采样/CDC。

PI 增益、Ki*Ts、Kaw、Ld/Lq/psi 等由同一外部参数派生并一次量化。当前按每次仿真/生成配置常量处理，不在本轮实现在线原子调参；保存原值、量化值和误差。Vdc 新端口改变只是依赖显式化，限幅器和 SVPWM 必须使用同一拍同一母线值。

除独立 FOC 的算术/数据类型与必要合法输入约束外，不改变：old-state PI 输出、Ki*Ts 积分、前拍 raw-minus-limited AW、原圆限幅规则、复位优先级、SVPWM 极性、原近似系数和采样相位。若工具要求运算顺序/架构替换，单列映射和误差证明，不暗改成另一种 FOC 或 PI。

### 3.3 已知数值边界必须先解决

- 复现原 SVPWM 零分母发生条件、候选支路选择及真实输出；在新实现中于除法前保护分母，不能先计算 0/0 再靠后级 Switch 隐藏 NaN。未选中的分支也必须数值定义完整。
- 保护只消除未定义候选值，合法输入的最终 duty/扇区行为保持。不要给所有分母粗暴加 epsilon，或仅把所有 NaN 最后改成0；选中支路若需要改变数学，先报告而非悄悄修正原参考。
- 原圆限幅的 `1e-6` 在拟定类型下不能意外量化成0；给出精度/范围分析。开方输入不得因平方和溢出变负；分母、商、缩放系数各自有足够范围。
- Sector 与 Switch 控制改为明确整数/boolean，保留原分界和零矢量含义。theta 的0/2pi、负值及超周期输入按原规范化行为验证；内部用标幺相位时适配必须唯一且可追踪。
- `DataTypeOverride=Off` 的编译结果才可作定点验收。数据通路/PI状态不得偷偷回转 double/single 进行开方、除法或三角运算；Scope、测试和外部 plant 的浮点不在此限制内。
- 不以增加一个100us Unit Delay解决工具报错。M2 不主动加算法级流水线延迟；需要硬件多拍算子的情况记录给 M3，在硬件时钟域设计。当前数值同拍完成不证明 FPGA 一个时钟周期能完成。

### 3.4 范围、位宽和首版能力声明

区分四栏：硬件/物理资料上限、当前控制配置约束、已有仿真观察范围、首版工程验证范围。先查已入库电机/驱动/采集资料和 M0 索引，不要求用户重新描述接口；旧 DSP 的 counts/数据类型不自动约束新算法。

缺少硬件最大值不阻塞独立浮点抽取或已知工况原型。Codex 可基于实际参数、已有场景及明确余量制定**首版受限验证范围**，在转换前写出数值、来源/假设、测试时长和不覆盖的项；不能称为驱动板额定范围或无限时长鲁棒保证。范围至少覆盖日常10mm、既有正负电流/速度/位置、0.5A对齐、负载、限幅/复位及下述边界测试。

输入范围不能由一次波形 min/max 直接定死；乘积、平方、求和、解耦、积分和 AW 要推导位增长。输出圆限幅不等于积分/原始电压被限制。没有全局积分钳位时，必须写清状态范围证明所需的输入/初态/持续时间条件；不能凭AW就声称永不溢出。

所有类型在一个配置源中管理：符号位、总位宽、小数位、分辨率、可表示范围、舍入、溢出规则、缩位点、系数量化误差与设计余量。工具可建议类型，但提交实际采用表。允许先用保守较宽位宽满足误差，再缩减；不统一套一种Q格式，不默认24位或照搬旧RTL。

本轮缩位默认采用明确的收敛舍入；宽中间量优先避免溢出，必要的存储边界使用显式饱和而非回绕。原算法限幅与**数值表示饱和**分开统计：验收范围内不应出现非预期数值饱和/溢出；出现就增位或报告范围不足，不能靠饱和隐藏。不得新增电流积分硬限当作定点设计的替代。非法/越界输入由测试适配显式拒绝或诊断，本轮不冒充完整硬件保护。
